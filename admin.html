1. الاتصال بـ GitHub

كيف بجيب التوكن؟
  1. من GitHub: Settings ثم Developer settings ثم Personal access tokens ثم Fine-grained tokens ثم Generate new token.
  2. بـ Repository access اختار Only select repositories وحدد هالريبو.
  3. بـ Permissions ثم Repository permissions خلي Contents على Read and write.
  4. انسخ التوكن والصقو هون. بدونو بتقدر تشوف الأعمال بس ما بتقدر تنشر.

التوكن بيضل على جهازك ولا بينرفع لأي مكان غير GitHub.

3. إضافة عمل

إضافة عدة روابط دفعة وحدة

كل سطر رابط. بتقدر تضيف عنوان بعد خط عمودي: الرابط | العنوان بالعربي | العنوان بالإنجليزي. النوع بيتاخد من الخانة التالية.

كيف بجيب رابط الفيديو من الدرايف؟
  1. افتح الفيديو بالدرايف واضغط مشاركة.
  2. خلي الوصول: أي شخص معه الرابط، بصلاحية مشاهد.
  3. انسخ الرابط والصقو هون. بدون هالخطوة ما بيشتغل الفيديو عند الزوار.

روابط يوتيوب وإنستغرام بتشتغل كمان، بس بتفتح بتبويب جديد بدل نافذة المشاهدة.
